## ▶️ How to Run

1. Install the Java Development Kit (JDK).
2. Clone this repository.
3. Open the project in Visual Studio Code.
4. Navigate to the required Java file.
5. Compile and run the program.

Example:

```bash
javac hello.java
java hello
```

Run these commands from the directory containing `hello.java`.
